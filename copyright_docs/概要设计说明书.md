## 一、引言

### 1.1 编写目的

本文档是HodoopForge项目的概要设计说明书，旨在从总体上描述系统的架构、模块划分、接口设计等内容，为详细设计和编码实现提供指导。

### 1.2 项目背景

HodoopForge 是一款企业级Hadoop集群部署与管理平台软件，解决 Apache Ambari 3.x 与 Apache Bigtop 3.5.0 之间联调困难、兼容性差、部署复杂等问题。

### 1.3 术语定义

| 术语 | 定义 |
|-----|------|
| Stack | Ambari中的组件栈定义，包含服务、组件、配置等信息 |
| MPack | Ambari Management Pack，管理包 |
| VDF | Version Definition File，版本定义文件 |
| Service Advisor | 服务建议器，提供配置建议 |

### 1.4 参考文档

1. HodoopForge 项目需求规格说明书 V1.0
2. Apache Ambari Architecture文档
3. Apache Bigtop Stack定义规范

## 二、系统总体设计

### 2.1 设计目标

1. **易用性**：提供一键式部署能力，降低部署门槛
2. **可靠性**：确保部署过程稳定可靠，支持故障恢复
3. **可扩展性**：支持自定义Stack扩展，方便集成新组件
4. **兼容性**：解决Ambari与Bigtop版本兼容问题

### 2.2 设计原则

1. **模块化设计**：各功能模块独立，低耦合高内聚
2. **配置驱动**：通过配置文件控制部署行为
3. **幂等性**：脚本可重复执行，不会产生副作用
4. **可观测性**：提供完整的日志和状态输出

## 四、模块设计

### 4.1 模块划分

| 模块编号 | 模块名称 | 功能描述 |
|---------|---------|---------|
| M001 | 部署模块 | 负责容器环境初始化和基础配置 |
| M002 | 仓库模块 | 负责本地YUM仓库构建和管理 |
| M003 | 集成模块 | 负责Bigtop Stack注入和版本更新 |
| M004 | 安装模块 | 负责Ambari Server/Agent安装 |
| M005 | 修复模块 | 负责兼容性问题修复 |
| M006 | 管理模块 | 负责集群服务管理 |

### 4.2 模块详细设计

#### 4.2.1 部署模块 (M001)

**功能描述**：初始化Docker容器环境，配置SSH免密登录

**输入**：
- 容器实例列表
- 基础软件包列表

**输出**：
- 初始化完成的容器环境
- SSH免密配置

**处理流程**：
```
开始
  │
  v
检查容器运行状态 ────[失败]──> 报错退出
  │
  │[成功]
  v
安装基础软件包
  │
  v
配置SSH服务
  │
  v
生成SSH密钥
  │
  v
分发公钥到所有节点
  │
  v
配置known_hosts
  │
  v
结束
```

**依赖关系**：
- 依赖Docker环境
- 依赖容器网络互通

#### 4.2.2 仓库模块 (M002)

**功能描述**：构建本地YUM仓库，提供离线安装支持

**输入**：
- Ambari RPM包目录
- Bigtop RPM包目录

**输出**：
- YUM仓库URL
- HTTP服务

**处理流程**：
```
开始
  │
  v
创建仓库目录
  │
  v
复制RPM包 ────[Ambari RPM]
  │
  │────[Bigtop RPM]
  v
生成仓库元数据(createrepo)
  │
  v
配置Nginx虚拟主机
  │
  v
启动Nginx服务
  │
  v
验证仓库可访问
  │
  v
结束
```

#### 4.2.3 集成模块 (M003)

**功能描述**：注入Bigtop 3.5.0 Stack定义到Ambari Server

**输入**：
- 父Stack版本号
- 组件版本映射表

**输出**：
- BIGTOP/3.5.0 Stack定义
- VDF文件

**处理流程**：
```
开始
  │
  v
检测现有Stack版本
  │
  v
确定父Stack版本
  │
  v
创建3.5.0 Stack目录
  │
  v
生成metainfo.xml
  │
  v
生成repoinfo.xml
  │
  v
更新各服务版本号
  │
  │──[HDFS: 3.3.6]
  │──[Hive: 4.0.1]
  │──[HBase: 2.6.2]
  │──[Spark: 3.5.6]
  v
修复已知兼容性问题
  │
  v
生成VDF文件
  │
  v
结束
```

#### 4.2.4 安装模块 (M004)

**功能描述**：安装和配置Ambari Server及Agent

**输入**：
- 数据库配置信息
- 节点列表

**输出**：
- 运行中的Ambari Server
- 已注册的Ambari Agent

**处理流程**：
```
开始
  │
  v
安装MySQL数据库
  │
  v
创建数据库和用户
  │
  v
安装Ambari Server RPM
  │
  v
执行ambari-server setup
  │
  v
导入数据库schema
  │
  v
注入Bigtop Stack
  │
  v
启动Ambari Server
  │
  v
[循环] 各节点安装Agent
  │
  v
配置Agent连接Server
  │
  v
启动Agent服务
  │
  v
结束
```

#### 4.2.5 修复模块 (M005)

**功能描述**：修复Hive等服务的兼容性问题

**输入**：
- 服务状态

**输出**：

- 正常运行的服务

**处理流程**：
```
开始
  │
  v
修复hive.exec.post.hooks配置
  │
  v
修复service_advisor.py
  │
  v
修复hive_check.py认证参数
  │
  v
修复HDFS目录权限
  │
  v
初始化Metastore schema
  │

  │
  v
结束
```

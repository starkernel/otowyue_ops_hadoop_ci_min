## 二、软件功能说明

### 2.1 软件概述

HodoopForge 是一款企业级Hadoop集群部署与管理平台软件，专为解决 Apache Ambari 3.x 与 Apache Bigtop 3.5.0及以上版本之间联调困难、兼容性差、部署复杂等问题而开发。

该软件在深度优化 Apache Ambari 的基础上，完美集成并增强了 Bigtop 的打包与组件管理能力，对相关 Stack、服务定义、元数据、部署脚本等进行了专项定制与重构，填补了当前开源生态中这一关键空白。

### 2.2 主要功能模块

#### （1）集群部署模块
- 提供一键式/向导式集群部署功能
- 支持多节点Docker容器化部署
- 自动化配置SSH免密登录、SELinux、网络等基础环境
- 本地YUM仓库自动构建与管理

#### （2）Stack集成模块
- 实现Ambari 3.1.0与Bigtop 3.5.0的深度集成
- 自动注入Bigtop 3.5.0 Stack定义
- 支持HDFS、YARN、Hive、HBase、Spark、Kafka、Flink等15+组件
- VDF（Version Definition File）自动生成与管理

#### （3）兼容性修复模块
- 修复Bigtop Stack与Ambari的兼容性问题
- 解决Hive 4.0.1与Ambari 3.1.0的集成问题
- 修复service_advisor.py中的配置bug
- 修复hive_check.py中的认证参数兼容性问题

#### （4）服务管理模块
- 继承Ambari Web UI的集群管理能力
- 支持服务启停、配置修改、监控告警
- 支持滚动升级和高可用配置
- 提供服务健康检查和故障诊断

#### （5）安全集成模块
- 内置Kerberos安全认证支持
- Ranger权限管理集成
- MySQL元数据库安全管理
- 凭证存储禁用与明文密码修复

#### （6）运维管理模块
- 集群健康检查与状态监控
- 配置文件备份与恢复
- 服务启停与故障诊断
- 集群扩缩容支持
- 日志收集与分析
- 性能测试与指标收集

### 2.3 技术特点

1. **首创性解决方案**：目前市面上首个彻底打通Ambari 3.1.x与Bigtop 3.5.x的集成平台
2. **容器化部署**：基于Docker的轻量级部署方案，支持快速环境搭建
3. **离线安装支持**：本地RPM包管理，无需互联网连接即可完成部署
4. **自动化修复**：内置多项兼容性修复脚本，自动解决已知问题
5. **可扩展架构**：支持自定义Stack扩展，方便集成第三方组件
6. **完整运维工具链**：提供健康检查、监控告警、备份恢复、扩缩容等全套运维工具

## 三、软件创新点与亮点

### 3.1 核心创新点

#### 创新点一：Ambari 3.x 与 Bigtop 3.5.x 的深度集成

**技术背景**：
Apache Ambari 3.1.0 发布时，其默认支持的 Bigtop 版本为 3.2.x，而 Apache Bigtop 3.5.0 已发布较长时间，两者之间存在严重的版本不匹配问题：
- Stack定义格式不兼容
- 组件版本号不匹配
- 包命名规则变化
- 服务元数据缺失

**创新方案**：
本软件通过以下技术手段实现了两者的深度集成：
1. 动态继承机制：自动检测现有Stack版本，继承并扩展至3.5.0
2. 元数据自动更新：批量更新所有服务的组件版本号
3. 包路径修复：修正bigtop-select的命令路径映射
4. VDF自动生成：根据组件清单自动生成版本定义文件

**技术效果**：
用户可直接在Ambari UI中选择Bigtop 3.5.0 Stack进行集群部署，无需手动修改任何配置文件。

#### 创新点二：Hive 4.0.1 兼容性修复

**技术背景**：
Hive 4.0.1 与 Ambari 3.1.0 存在多项兼容性问题：
- service_advisor.py 中 hive.exec.post.hooks 配置返回空格而非空字符串
- hive_check.py 中 auth=noSasl 参数大小写敏感问题
- Metastore schema 初始化失败

**创新方案**：
1. 定位并修复 service_advisor.py 中的空格值bug
2. 修正 hive_check.py 中的认证参数为 auth=none
3. 提供独立的 fix-hive.sh 修复脚本
4. 在部署脚本中预置修复逻辑

**技术效果**：
Hive服务可正常启动并通过Ambari健康检查，告警恢复正常。

#### 创新点三：容器化快速部署方案

**技术背景**：
传统Hadoop集群部署需要准备多台物理机或虚拟机，配置复杂，资源消耗大。

**创新方案**：
1. 基于Docker Compose的多节点集群定义
2. 使用 bigtop/puppet 官方镜像作为基础环境
3. 自动化SSH配置和主机名解析
4. 本地YUM仓库容器化托管

**技术效果**：
用户可在单台服务器上快速搭建4节点Hadoop集群，部署时间从数小时缩短至30分钟内。

### 3.2 技术亮点

1. **填补市场空白**：目前市面上没有同类产品能够实现Ambari 3.1.x与Bigtop 3.5.x的无缝集成
2. **纯开源架构**：基于Apache开源组件构建，无厂商锁定风险
3. **生产级可用**：经过实际测试验证，支持企业级生产环境部署
4. **文档完善**：提供详细的部署指南和运维手册
5. **持续维护**：支持后续版本升级和功能扩展

## 六、软件使用说明

### 6.1 部署步骤

```bash
# 1. 进入项目目录
cd ambari3

# 2. 启动Docker容器
docker compose up -d

# 3. 初始化节点环境
cd scripts && ./setup.sh

# 4. 构建本地YUM仓库
./setup-ambari-repo.sh

# 5. 安装Ambari Server
./install-ambari-server.sh

# 6. 安装Ambari Agent
./install-ambari-agent.sh

# 7. 访问Web界面
# http://localhost:20609 (admin/admin)
```

### 6.2 系统要求

- 宿主机内存：建议32GB以上
- 宿主机存储：建议100GB以上
- Docker版本：20.x及以上
- 操作系统：支持Docker的Linux发行版

- **格式**：每页约50行

文档内容涵盖：

## 三、申请流程

### 3.1 准备材料

1. 填写软件著作权登记申请表
2. 准备源程序鉴别材料
3. 准备文档鉴别材料
4. 准备申请人身份证明

### 3.2 提交申请

1. 登录中国版权保护中心网站
2. 在线填写申请信息
3. 上传鉴别材料
4. 提交申请

### 3.3 审核流程

1. 形式审查（约30个工作日）
2. 实质审查（约60个工作日）
3. 登记公告
4. 领取证书

## 五、注意事项

### 5.1 材料格式要求

- 鉴别材料每页不少于50行
- 源代码应有适当注释
- 文档应结构清晰、内容完整
- 使用A4纸打印，左侧装订

### 5.2 申请注意事项

- 软件名称应与实际软件一致
- 版本号应准确填写
- 开发完成日期应在申请日期之前
- 首次发表日期可填写开发完成日期

### 5.3 常见问题

**Q1: 源代码不足60页怎么办？**

A: 如果源代码不足60页，应提交全部源代码。

**Q2: 文档鉴别材料选择哪种文档？**

A: 通常选择用户手册或操作说明书，内容应能体现软件功能。

**Q3: 申请周期多长？**

A: 一般情况约3个月，加急申请可缩短至1个月。

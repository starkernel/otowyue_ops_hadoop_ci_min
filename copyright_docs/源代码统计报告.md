## 一、统计概述

本报告按照中国软件著作权登记申请要求，对 HodoopForge 项目的源代码进行系统性统计。

### 1.1 统计范围

- Shell 脚本文件（.sh）
- Python 脚本文件（.py）
- 配置文件（.yml、.xml、Vagrantfile等）
- 不含：RPM包、文档文件（.md）、git元数据

### 1.2 统计结果摘要

| 统计项 | 数值 |
|-------|------|
| 源代码文件总数 | 55 个 |
| 源代码总行数 | 4,632 行 |

| Python脚本行数 | 1,766 行（38.1%）|

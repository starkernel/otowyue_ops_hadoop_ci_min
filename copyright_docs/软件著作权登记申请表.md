```
三、批量版本更新：自动遍历所有服务目录，批量更新15个以上组件的版本元数据，确保Ambari UI正确识别Bigtop 3.5.0组件。

五、容器化快速部署：基于Docker Compose的4节点集群定义，部署时间从数小时缩短至1小时以内，支持单机模拟多节点生产环境。

六、完全离线支持：通过本地Nginx HTTP仓库托管全部RPM包，无需外网连接即可完成Ambari及Bigtop全部组件安装。
```

## 二、软件用途和技术特点

### 2.1 软件用途

HodoopForge 是一款企业级Hadoop集群部署与管理平台软件，主要用于：

1. 大数据平台的快速部署与搭建
2. Hadoop集群的全生命周期管理
3. 多节点容器化环境的一键部署
4. Apache Ambari与Bigtop的集成与兼容

### 2.2 技术特点

1. **首创性**：目前市面上首个彻底打通Ambari 3.1.x与Bigtop 3.5.x的集成平台
2. **容器化**：基于Docker的轻量级部署方案
3. **离线支持**：本地RPM包管理，无需互联网连接
4. **自动修复**：内置兼容性修复脚本
5. **可扩展**：支持自定义Stack扩展

### 2.3 运行环境

- 操作系统：Linux（CentOS/RHEL/Rocky Linux 8.x）
- 硬件环境：x86_64架构服务器，8GB以上内存
- 软件环境：Docker 20.x+、Docker Compose 2.x+、Java 8/17

### 2.4 编程语言

- Shell Script（Bash）
- Python 3
- YAML（Docker Compose配置）
- XML（配置文件）

### 2.5 源程序量

- 总行数：约4,632行
- 文件数：55个
